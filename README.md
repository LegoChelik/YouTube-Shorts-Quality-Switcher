# YouTube Shorts Quality Switcher

Юзерскрипт добавляет пункт **Quality / Качество** в меню ⋮ плеера YouTube Shorts.

## Возможности

- Ручной выбор из доступных разрешений и режим «Авто».
- Выбранное качество также применяется к следующим шортсам в той же вкладке.
- Если выбранное разрешение недоступно, скрипт подбирает доступное и применяет исходный выбор, когда он снова доступен.
- Подписи меню на английском и русском.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [ссылку установки скрипта](https://github.com/LegoChelik/YouTube-Shorts-Quality-Switcher/raw/refs/heads/main/script.user.js).
3. В окне Tampermonkey нажмите **Install / Установить**.
4. Перезагрузите ранее открытые вкладки YouTube Shorts.

## Использование

Откройте шортс, запустите воспроизведение и нажмите **⋮ → Quality / Качество**. Выберите разрешение или режим «Авто». Галочка показывает выбранный вариант.

Проверено в Firefox с Tampermonkey.

# English Description

This userscript adds a **Quality** option to the ⋮ menu in the YouTube Shorts player.

## Features

- Manually select an available resolution or use Auto mode.
- Your quality selection also applies to subsequent Shorts in the same tab.
- If your selected resolution is unavailable, the script picks an available one and restores your original selection when it becomes available again.
- Menu labels are available in English and Russian.

## Installation

1. Install the Tampermonkey extension.
2. Open the [script installation link](https://github.com/LegoChelik/YouTube-Shorts-Quality-Switcher/raw/refs/heads/main/script.user.js).
3. Click **Install** in the Tampermonkey prompt.
4. Reload any open YouTube Shorts tabs.

## Usage

Open a Short, start playback, and select **⋮ → Quality**. Choose a resolution or select **Auto**. A checkmark indicates the selected option.

Tested in Firefox with Tampermonkey.
